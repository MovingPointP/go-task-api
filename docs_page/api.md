# API 仕様

- **Base URL**: `/api/v1`
- **Content-Type**: `application/json`
- **Swagger UI**: `/swagger/index.html`

---

## 認証 API

### POST /auth/register

**説明**: メールアドレスとパスワードでユーザーを新規登録し、JWT を返す

**認証**: 不要

**リクエスト**

| フィールド | 型 | 必須 | 説明 |
|---|---|---|---|
| `email` | string | ○ | メールアドレス形式 |
| `password` | string | ○ | 8文字以上 |

```json
{
  "email": "user@example.com",
  "password": "password123"
}
```

**レスポンス (201 Created)**

| フィールド | 型 | 説明 |
|---|---|---|
| `token` | string | JWT アクセストークン |
| `email` | string | 登録したメールアドレス |

```json
{
  "token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
  "email": "user@example.com"
}
```

**エラー**

| ステータスコード | 説明 |
|---|---|
| 400 | バリデーションエラー（メール形式不正、パスワード8文字未満） |
| 409 | メールアドレスがすでに登録済み |
| 500 | サーバー内部エラー |

---

### POST /auth/login

**説明**: メールアドレスとパスワードでログインし、JWT を返す

**認証**: 不要

**リクエスト**

| フィールド | 型 | 必須 | 説明 |
|---|---|---|---|
| `email` | string | ○ | メールアドレス |
| `password` | string | ○ | パスワード |

```json
{
  "email": "user@example.com",
  "password": "password123"
}
```

**レスポンス (200 OK)**

| フィールド | 型 | 説明 |
|---|---|---|
| `token` | string | JWT アクセストークン |
| `email` | string | ログインしたメールアドレス |

**エラー**

| ステータスコード | 説明 |
|---|---|
| 400 | バリデーションエラー |
| 401 | メールアドレスまたはパスワードが不正 |
| 500 | サーバー内部エラー |

## タスク API

> 全エンドポイントで `Authorization: Bearer <token>` ヘッダーが必要です。
> タスク操作はログインユーザー自身のタスクのみに限定されます。

### Task オブジェクト

| フィールド | 型 | 説明 |
|---|---|---|
| `id` | uint | タスク ID |
| `user_id` | uint | 所有ユーザー ID |
| `title` | string | タスクタイトル |
| `description` | string | タスク説明（省略可） |
| `completed` | bool | 完了フラグ |
| `created_at` | string (RFC3339) | 作成日時 |
| `updated_at` | string (RFC3339) | 更新日時 |

---

### POST /tasks

**説明**: 新しいタスクを作成する

**認証**: 必要

**リクエスト**

| フィールド | 型 | 必須 | 説明 |
|---|---|---|---|
| `title` | string | ○ | タスクタイトル |
| `description` | string | - | タスク説明 |

```json
{
  "title": "買い物",
  "description": "牛乳・卵・パン"
}
```

**レスポンス (201 Created)**: Task オブジェクト

**エラー**

| ステータスコード | 説明 |
|---|---|
| 400 | `title` が未指定 |
| 401 | 認証エラー |
| 500 | サーバー内部エラー |

---

### GET /tasks

**説明**: ログインユーザーのタスクを全件取得する

**認証**: 必要

**レスポンス (200 OK)**: Task オブジェクトの配列

```json
[
  {
    "id": 1,
    "user_id": 1,
    "title": "買い物",
    "description": "牛乳・卵・パン",
    "completed": false,
    "created_at": "2026-04-26T10:00:00Z",
    "updated_at": "2026-04-26T10:00:00Z"
  }
]
```

**エラー**

| ステータスコード | 説明 |
|---|---|
| 401 | 認証エラー |
| 500 | サーバー内部エラー |

---

### GET /tasks/:id

**説明**: 指定 ID のタスクを取得する

**認証**: 必要

**パスパラメータ**

| パラメータ | 型 | 説明 |
|---|---|---|
| `id` | int | タスク ID |

**レスポンス (200 OK)**: Task オブジェクト

**エラー**

| ステータスコード | 説明 |
|---|---|
| 400 | `id` が整数でない |
| 401 | 認証エラー |
| 404 | タスクが存在しない、または他ユーザーのタスク |

---

### PUT /tasks/:id

**説明**: 指定 ID のタスクを更新する

**認証**: 必要

**パスパラメータ**

| パラメータ | 型 | 説明 |
|---|---|---|
| `id` | int | タスク ID |

**リクエスト**

| フィールド | 型 | 必須 | 説明 |
|---|---|---|---|
| `title` | string | ○ | タスクタイトル |
| `description` | string | - | タスク説明 |
| `completed` | bool | - | 完了フラグ（デフォルト: false） |

```json
{
  "title": "買い物（更新）",
  "description": "牛乳のみ",
  "completed": true
}
```

**レスポンス (200 OK)**: 更新後の Task オブジェクト

**エラー**

| ステータスコード | 説明 |
|---|---|
| 400 | `id` が整数でない、または `title` が未指定 |
| 401 | 認証エラー |
| 404 | タスクが存在しない、または他ユーザーのタスク |

---

### DELETE /tasks/:id

**説明**: 指定 ID のタスクを削除する

**認証**: 必要

**パスパラメータ**

| パラメータ | 型 | 説明 |
|---|---|---|
| `id` | int | タスク ID |

**レスポンス (204 No Content)**: ボディなし

**エラー**

| ステータスコード | 説明 |
|---|---|
| 400 | `id` が整数でない |
| 401 | 認証エラー |
| 404 | タスクが存在しない、または他ユーザーのタスク |
